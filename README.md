# E-Commerce Backend

REST API for an E-Commerce application (product listing, cart, authentication, order management).

## Tech Stack
Node.js, Express, MongoDB Atlas, Mongoose, JWT

## Setup
1. Clone the repo
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in your values
4. Run `npm run dev`

> Full documentation will be added as features are completed.
